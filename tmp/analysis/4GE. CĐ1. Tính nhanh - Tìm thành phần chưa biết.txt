I. KIẾN THỨC CẦN NHỚ. 
* Các tính chất của phép cộng, phép trừ. 
 
a + b = b + a       
 
 
 
   
(a + b) + c = a + (b + c)                
 
a – b – c = a – (b + c) 
 
 
 
a – b + c = a – (b – c) 
* Các tính chất của phép nhân, phép chia. 
 a × b = b × a          
 
 
 
 
a × b × c = a × (b × c) 
 
 a : b x c = a x c : b 
 
 
 
 
a : b : c = a : (b x c) 
* Quy tắc nhân một số với một tổng hoặc một hiệu - Đặt thừa số chung 
a × (b +c) = a × b + a × c                     
a × (b – c) = a × b – a × c 
* Quy tắc một tổng hoặc hiệu chia cho một số. 
(a + b) : c = a : c + b : c (c khác 0)             (a - b) : c = a : c - b : c (c khác 0)             
* Sử dụng tính chất của dãy số cách đều. 
* Một số công thức cần ghi nhớ: 
+ Số các số hạng = (số hạng cuối – số hạng đầu) : khoảng cách + 1  (với dãy số tăng dần) 
+ Số các số hạng = (số hạng đầu – số hạng cuối) : khoảng cách + 1 (với dãy số giảm dần) 
+ Tổng dãy số = (số đầu + số cuối) × số các số hạng : 2 
+ Số hạng thứ n = số đầu + khoảng cách × (n – 1) (với dãy số tăng dần) 
+ Số hạng thứ n = số đầu - khoảng cách × (n – 1) (với dãy số giảm dần)
