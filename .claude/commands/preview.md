# Preview trang HTML

Mở file `output/html/toan-bo-de-cuong.html` trong browser mặc định để kiểm tra.

## Checklist kiểm tra
1. Bấm "Gạch chân từ khóa" → từ khóa gạch chân đỏ hiện ra
2. Bấm "Phân tích từ khóa" → mở phần phân tích + diagram (nếu có)
3. Bấm "Xem lời giải" → hộp thoại nhập mật khẩu (000000)
4. Kiểm tra trên mobile (responsive)
5. Kiểm tra in ấn (Ctrl+P)

- TL8: Viết thêm chữ số
